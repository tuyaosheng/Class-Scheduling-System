# 中小学排课系统

面向中小学（初中）教务的自动排课工具。读入教务已经人工编好的任课表（谁带哪个班）和排课规则，用 OR-Tools CP-SAT 求解每节课应该排在哪个时间格，输出课表。

## 这个系统在做什么

- **输入**：`任课与排课说明.xlsx`（任课记录：姓名/任教班/周课时/禁排节次等）+ 教务的规则配置。
- **输出**：满足硬性约束（教师不分身、班级不重课、场地不超容量……）且尽量贴近教务软性偏好的课表，导出为 Excel。
- **不做任课分配**——谁带哪个班由教务人工决定，是系统的输入而不是输出。

无解时不会只吐一句"排不出来"：系统分三层诊断——求解前的毫秒级预检（直接定位是哪位老师课时超载）、求解后的最小冲突集（CP-SAT 给出具体是哪几条规则互相打架）、以及把结果翻译成人话的 AI 辅助说明。

约束编译（把规则变成 CP-SAT 约束）和结果校验（检查解是否合规）是两套完全独立的实现，互不复用代码——避免同一个建模错误同时骗过两边。

## 技术栈

```
后端    Python 3.10 · FastAPI · uvicorn · OR-Tools CP-SAT · pydantic 2 · openpyxl · PyYAML
AI      Anthropic SDK
前端    Vue 3 + Vite · SortableJS · ECharts
打包    PyInstaller --onefile（前端构建产物内嵌进单个 exe）
```

交付形态是本地工具：教务拿到的是一个 exe，不需要账号体系，不是 SaaS。

## 快速开始

### 环境准备

```bash
pip install -r requirements.txt
```

Windows 控制台默认 GBK 编码，若自己写临时脚本，记得设置 `PYTHONIOENCODING=utf-8`。

### 跑测试

```bash
python -m pytest -q
```

### 导入 Excel 并核对规则解析结果

Excel 里的禁排/固定节次列是自然语言，导入时会把解析结果回显出来，供教务逐条确认，避免歧义被静默接受：

```bash
# 先跑一遍，不落盘，只看解析结果对不对
python -m scheduler.cli import 任课与排课说明.xlsx --grade 初三

# 确认无误后固化成配置文件
python -m scheduler.cli import 任课与排课说明.xlsx --grade 初三 --write
```

### 排课

```bash
python -m scheduler.cli solve --out output/初三课表.xlsx
```

流程是：L1 预检 → CP-SAT 求解 → 独立校验 → 导出 Excel。退出码 `0` 成功、`1` 无解（已打印最小冲突集）、`2` 预检未通过（连求解器都没进）。

### Web 界面

```bash
cd scheduler/web
npm install
npm run dev
```

后端服务（FastAPI）随 CLI 一并提供，具体启动方式见 `scheduler/api/` 下的实现。

## 性能基线

初三 32 班（512 任务 / 23,040 变量）级别的规模，实测 CP-SAT 求解 0.6 秒内给出最优解，独立校验 0 处违规，预检毫秒级零假阳性。这个量级决定了产品形态——排课可以做成交互级操作："改一条规则立刻重排""拖动一节课后自动重算"。若实现后明显变慢，通常是建模粒度出了问题，不是求解器能力不够，详见 `CLAUDE.md`「性能基线」一节。
